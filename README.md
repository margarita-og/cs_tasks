# C# Tasks

Набор консольных приложений на C#, решающих различные задачи.

## Структура проектов

```
cs_tasks/
├── task_1/         # Задача 1: Подсчёт градусов
├── task2/          # Задача 2: Сумма чисел 
├── task3/          # Задача 3: Рандомное число
├── task4/          # Задача 4: Проверка пароля
└── task5/          # Задача 5: Информация о введённом тексте
```

## Запуск проектов

### Предварительные требования
- [.NET 6.0 SDK] или новее

### Способ 1: Через командную строку
```bash
# Перейти в папку с проектом
cd task_1

# Собрать и запустить
dotnet run

# Или отдельно
dotnet build
dotnet run
```

### Способ 2: Через Visual Studio Code
1. Откройте папку проекта в VS Code
2. Нажмите `F5` или выполните в терминале:
```bash
dotnet run
```

## Примечания
- Каждый проект полностью независим
- Для каждого проекта нужно выполнять `dotnet run` из его папки
- Файлы сборки (bin/, obj/) добавлены в .gitignore
